# خريطة توضيحية لـ Cima4u Category Crawler Workflow

## نظرة عامة
هذا الـ workflow يعمل تلقائياً **كل ساعتين** لاستخراج الأفلام والمسلسلات من موقع Cima4u ورفعها إلى DoodStream وحفظها في قاعدة بيانات Supabase.

يعتمد فقط على **Category Crawler** الذي يفحص جميع التصنيفات (أفلام + مسلسلات).

---

## مسار الـ Workflow (من البداية للنهاية)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. البداية                                                   │
│    - جدولة زمنية: كل ساعتين (cron: 0 */2 * * *)            │
│    - أو تشغيل يدوي عبر GitHub Actions UI                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. استخراج الكود (Checkout)                                 │
│    - تحميل الكود من المستودع                                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. إعداد البيئة (Setup)                                     │
│    - تثبيت Python 3.11                                      │
│    - تثبيت المكتبات من requirements.txt                     │
│    - تثبيت Playwright Chromium (للمتصفح الآلي)              │
│    - تثبيت xvfb و aria2 (للأدوات المساعدة)                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. تشغيل FlareSolverr                                       │
│    - تشغيل حاوية Docker لتجاوز Cloudflare                   │
│    - المنفذ: 8191                                          │
│    - يسمح بالوصول إلى صفحات Cima4u المحمية                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 5. استعادة Cache (Restore Cache)                            │
│    - استعادة processed_cima4u_movies.json (الروابط المعالجة) │
│    - استعادة tv_series.db (قاعدة بيانات المسلسلات)          │
│    - هذا يمنع معالجة نفس المحتوى مرتين                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 6. تشغيل Category Crawler (التصنيفات)                      │
│    - تنفيذ: python3 cima4u_crawler.py                      │
│    - المعاملات:                                             │
│      • --mode all (أفلام + مسلسلات)                         │
│      • --max-pages 20 (حد أقصى 20 صفحة لكل تصنيف)          │
│      • --max-movies 50 (حد أقصى 50 فيديو لكل تصنيف)        │
│      • --all-categories (جميع التصنيفات)                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 7. معالجة التصنيفات (Processing Categories)                │
│                                                             │
│  التصنيفات المعالجة:                                       │
│  ├─ أفلام أجنبية (https://cimafu.cam/category/افلام-اجنبي/)│
│  ├─ أفلام آسيوية (https://cimafu.cam/category/افلام-اسيوي/)│
│  ├─ مسلسلات أجنبية (https://cimafu.cam/category/مسلسلات-اجنبي/)│
│  └─ مسلسلات آسيوية (https://cimafu.cam/category/مسلسلات-اسيوي/)│
│                                                             │
│  لكل تصنيف:                                                │
│  ├─ تحميل الصفحة عبر FlareSolverr أو Playwright             │
│  ├─ استخراج روابط الأفلام/Cلقات من HTML                   │
│  ├─ التحقق من عدم وجود المحتوى في Supabase مسبقاً         │
│  ├─ استدعاء jibi_bot لرفع الفيديو إلى DoodStream          │
│  ├─ الحصول على filecode و tmdb_id                          │
│  ├─ حفظ البيانات في Supabase:                              │
│  │  • الأفلام → جدول movies                                │
│  │  • المسلسلات → جدول tv_episodes                         │
│  └─ تحديث processed_cima4u_movies.json                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 8. حفظ Cache المحدث (Save Cache)                           │
│    - رفع processed_cima4u_movies.json المحدث               │
│    - رفع tv_series.db المحدث                                │
│    - حفظ كـ artifacts لمدة 7 أيام                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 9. عرض الملخص (Display Summary)                            │
│    - عدد الروابط المعالجة من التصنيفات                    │
│    - آخر تحديث                                              │
│    - حالة قاعدة بيانات المسلسلات                            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 10. النهاية                                                 │
└─────────────────────────────────────────────────────────────┘
```

## تفاصيل إضافية

### المتغيرات البيئية المطلوبة
- `SUPABASE_URL`: رابط قاعدة بيانات Supabase
- `SUPABASE_KEY`: مفتاح الوصول لـ Supabase
- `TMDB_API_KEY`: مفتاح API TMDB للبحث عن معلومات الأفلام
- `DOODSTREAM_API_KEY`: مفتاح API DoodStream للرفع

### خيارات التشغيل اليدوي
يمكنك تشغيل الـ workflow يدوياً من GitHub Actions UI وتحديد:
- **Mode**: `all` (الكل), `movies` (أفلام فقط), `tv` (مسلسلات فقط)
- **Max Pages**: عدد الصفحات القصوى لكل تصنيف (الافتراضي: 20)
- **Max Movies**: عدد الفيديوهات القصوى لكل تصنيف (الافتراضي: 50)

### الملفات المستخدمة
- `processed_cima4u_movies.json`: يحفظ الروابط المعالجة من التصنيفات لتجنب التكرار
- `tv_series.db`: قاعدة بيانات SQLite المحلية للمسلسلات والحلقات

## كيف يعمل jibi_bot داخل الـ workflow

```
cima4u_crawler.py يستدعي jibi_bot لكل فيديو:
  ↓
jibi_bot يستخرج السيرفرات من صفحة المشاهدة
  ↓
يحاول حل روابط التدفق (m3u8/mp4) عبر Playwright
  ↓
يرفع الفيديو إلى DoodStream عبر API
  ↓
يعيد filecode و tmdb_id
  ↓
cima4u_crawler يحفظ البيانات في Supabase
```

---

## الفوائد الرئيسية

1. **أتمتة كاملة**: يعمل كل ساعتين بدون تدخل يدوي
2. **تجنب التكرار**: يستخدم cache و Supabase pre-check
3. **شمولية**: يعالج جميع التصنيفات (أفلام + مسلسلات)
4. **مرونة**: يمكن تشغيله يدوياً بخيارات مخصصة
5. **تتبع**: يحفظ الحالة في cache و artifacts
